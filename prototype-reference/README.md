# Prototype reference

The original ArchiveHub interface prototype, kept untouched as a visual reference (ADR-017). Its replies are scripted and its data is sample data; it is not the architecture.

**Awaiting files:** the prototype zip (React + Vite: `src/App.jsx`, `src/styles.css`, `index.html`, `package.json`, `vite.config.js`). If the separate `Main.dc.html` / `support.js` export exists, it goes in `html-export/`.

Run it with Node 18+: `npm install` then `npm run dev`.
